=== 1. probe_signup.py ===
Probes a curated list of public account-creation / API surfaces and records the gate class.
- Define TARGETS as a list of dicts: {"id","name","category","url"}  (~30 entries).
- Use ONE honest User-Agent that declares itself a bot and says why:
  "AgentGatesBot/0.1 (+https://agentgates.surge.sh; autonomous-agent reachability measurement)"
  Label it clearly in the code as an honest crawler UA. Do NOT spoof a browser.
- For each target, in this order:
  a) GET https://<host>/robots.txt. Parse it with a simple regex/parser. Determine whether the agent path is disallowed for "*" or for any AI-agent token (GPTBot, ClaudeBot, Claude-Web, CCBot, Google-Extended, PerplexityBot, Bytespider, Amazonbot, Applebot-Extended, meta-externalagent). Store: robots_status, robots_disallows_path (bool), ai_agents_named (list), robots_raw_len.
  b) If robots disallows the path for "*", DO NOT fetch the page. Record gate="robots-disallow" and outcome="BLOCKED". This is itself the finding.
  c) Otherwise GET the target URL once. Follow redirects (max 5), 20s timeout. Record: http_status, final_url, server (Server header), elapsed_ms.
  d) Detect anti-bot from headers: cf-ray / cf-mitigated / server contains "cloudflare" -> vendor "cloudflare"; "akamai","datadome","perimeterx","imperva","sucuri","fastly" likewise.
  e) Detect a challenge/interstitial from the BODY (lowercase substring test): "just a moment", "cf-challenge", "attention required", "enable javascript and cookies to continue", "checking your browser", "ddos protection by", "verify you are human" -> challenge_detected=True.
  f) Detect signup requirement signals in the body: presence of <input type="password", and substring "phone"/"mobile number" -> phone_required_signal; "captcha","recaptcha","hcaptcha","turnstile","g-recaptcha" -> captcha_signal; "email" -> email_signal; oauth providers ("google","apple","github","microsoft" near "sign in with") -> oauth_available.
  g) Classify gate (pick the FIRST that applies, in this priority order):
     "robots-disallow" > "captcha" > "phone" > "pay-per-crawl" (http 402) > "waf-challenge" (challenge_detected) > "human-approval" (body mentions "approval","approved","invitation","invite only","application") > "email" (email input or email_signal + password field) > "open".
     outcome = "BLOCKED" if gate in (robots-disallow, captcha, phone, pay-per-crawl, waf-challenge, human-approval) else "REACHABLE".
- Politeness: max 4 concurrent workers, and a >=1.5s gap between requests to the SAME host. Randomised 0.3-0.9s jitter between target starts. Never retry more than once; never hammer.
